## 四、免登链路怎么验

**本地已验证（代码层）**：
- URL 带 `?code=xxx` → 前端发 `{code}` 走生产登录管道（假 code 会被企微拒绝返回 401，属正常）
- 企微内置浏览器（UA 含 wxwork）+ 已配置 corpid/agentid → 自动跳 `open.weixin.qq.com` 静默授权
- 普通浏览器 → dev 直登，行为与历史一致

**上线三步（部署侧）**：
1. `dist/build/h5` 部署到备案域名，nginx 反代后端 3000；
2. 企微管理后台 → 自建应用 → 把该域名设为「网页授权及 JS-SDK 可信域名」；
3. `.env.production` 填真实 corpid/agentid 重新构建；自建应用工作台主页指向部署地址。
完成后员工在企微里点开即免登进入本人首页。
